# HTML Training with GitHub Copilot

Welcome to the HTML Training repository! This project is designed to help you learn HTML, CSS, and JavaScript fundamentals while practicing with GitHub Copilot.

## 🎯 Learning Objectives

By completing this training, you will be able to:
- Write semantic HTML5 markup
- Style web pages using CSS3
- Add interactivity with JavaScript
- Create responsive web designs
- Build accessible web forms
- Use GitHub Copilot to accelerate web development

## 📚 Course Content

This repository includes examples and exercises covering:

1. **HTML Basics**
   - Document structure
   - Headings and paragraphs
   - Links and images
   - Lists (ordered and unordered)

2. **HTML Forms**
   - Input fields (text, email, etc.)
   - Textareas and select dropdowns
   - Form validation
   - Submit handling

3. **Semantic HTML5**
   - Header, nav, main, section, article
   - Aside and footer elements
   - Proper document structure

4. **Multimedia**
   - Embedding images
   - Video and audio elements
   - Responsive media

5. **CSS Styling**
   - Selectors and properties
   - Layout and positioning
   - Responsive design with media queries
   - Transitions and effects

6. **JavaScript Interactivity**
   - DOM manipulation
   - Event handling
   - Form validation
   - Smooth scrolling

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, or Edge)
- A text editor (VS Code recommended for GitHub Copilot)
- Basic understanding of how the web works

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/ismailandao/html_copilot.git
   cd html_copilot
   ```

2. Open `index.html` in your web browser:
   - Double-click the file, or
   - Right-click and select "Open with Browser", or
   - Use a local development server

### Using with GitHub Copilot

1. Install [Visual Studio Code](https://code.visualstudio.com/)
2. Install the [GitHub Copilot extension](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot)
3. Open this project in VS Code
4. Try the practice exercises below with Copilot's assistance

## 💻 Practice Exercises

Use GitHub Copilot to help you complete these challenges:

### Beginner Level
1. Add a new section about HTML tables with a 3x4 table example
2. Create a photo gallery with at least 6 images in a grid layout
3. Add a "Back to Top" button that appears when scrolling down

### Intermediate Level
4. Build a responsive navigation menu that collapses on mobile devices
5. Create a multi-step form with validation
6. Add a dark mode toggle using CSS variables and JavaScript

### Advanced Level
7. Implement a filterable content gallery
8. Create an accordion component for FAQ section
9. Build a simple image carousel/slider
10. Add animations and transitions to enhance user experience
